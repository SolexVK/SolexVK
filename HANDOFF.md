# Передача дел: приложение «Тай-Чи»

Состояние на 15 ноября 2026 года. Ветка `Тай-Чи`, последний рабочий коммит — «Фон из живых записей вместо синтеза».

## Что это

Личное приложение (PWA) для занятий тай-чи и цигун с голосом мастера. Ученик — мужчина 56 лет:

- рост 182 см, вес 113 кг, сидячий образ жизни;
- боль в пояснице и между лопатками, отдаёт в ноги;
- протрузия C5–C6;
- гипертония, низкий тестостерон.

Отсюда в программе щадящие ограничения: нет кругов головой, запрокидывания и задержки дыхания, нет глубоких приседаний, давление измеряется перед занятием.

- Приложение: https://solexvk.github.io/SolexVK/ — папка `docs/`, раздаёт GitHub Pages с ветки `Тай-Чи`.
- Сервер ученика: `https://taichi.aidemiko.ru` — папка `server/`.

## Устройство приложения (`docs/`)

Чистые ES-модули без сборки. Все данные лежат в localStorage под ключом `taichi.state.v1` и синхронизируются с сервером.

| Файл | Что делает |
|---|---|
| `js/app.js` | Экраны: главная, занятие, дневник, прогресс, мастер, настройки (темы, музыка, язык, сервер, авторы) |
| `js/course.js`, `program.js`, `flows.js`, `flow-lines.js` | Упражнения, уровни (4 этапа на уровень), утро / день / вечер |
| `js/session.js` | Ход занятия: шаги, счёт, дыхание, голосовые команды |
| `js/interview.js`, `kb.js` | Знакомство с мастером (анкета около 20 вопросов, 3 теста), опрос перед занятием, правила безопасности |
| `js/master.js`, `brain.js`, `ai-request.js` | Чат с мастером. Без ИИ — ответы на частые вопросы по правилам, с ИИ — через сервер (Haiku 5.5 для бесед, Sonnet 5.5 для программы и недельных пересмотров) |
| `js/coach.js`, `pose.js` | Камера: MediaPipe (`vendor/`, `models/`) следит за позой и даёт подсказки |
| `js/voice.js` | Голос мастера: готовые записи `audio/<ключ>.mp3`, для остального голос телефона. Сигнал «мастер говорит» для приглушения фона |
| `js/ambient.js` | Фоновый звук (см. ниже) |
| `js/theme.js`, `css/` | Шесть восточных цветовых тем |
| `js/i18n.js`, `js/lang/en.js` | Язык интерфейса RU/EN |
| `js/sync.js`, `store.js` | Хранение и синхронизация с сервером |
| `sw.js` | Service worker. Сейчас `VERSION = 'taichi-v10'` |

**Service worker.** Файлы приложения берутся сначала из сети. Тяжёлые файлы (`vendor/mediapipe`, `models`, `audio`, `sounds`) — сначала из кэша. Запросы с заголовком Range идут мимо кэша, иначе на iPhone не играют мелодии. **При любом изменении файлов поднимайте `VERSION`**, иначе телефон покажет старую версию.

### Голос мастера

- Голос — Baldur Sanjin, Coqui XTTS-v2 (лицензия CPML, только некоммерческое использование).
- 352 записи лежат в `docs/audio/`.
- Скорость и тембр пользователя устраивают. **Не менять.**
- Озвучка — `tools/voice/` (инструкция в его README). Нужны coqui-tts, faster-whisper, librosa и ffmpeg. В облачном контейнере это окружение пропадает, его придётся ставить заново.
- Голос мастера в занятиях всегда русский, даже в английском интерфейсе.
- Ручки «Скорость речи» (0,85–1,25×) и «Высота голоса» (±3 полутона) — в настройках, общие для всех фраз
  (`settings.voiceSpeed`, `settings.voicePitch`). Записи обрабатываются на телефоне: `js/voicefx.js` (WSOLA +
  пересэмплирование), варианты фраз кэшируются в памяти, готовятся в фоне после загрузки занятия.
  Длина такта считается по исходной записи (`voice.clipSeconds`), поэтому темп упражнений от ручек не зависит;
  если медленный голос не влезает в такт, фраза со счётом ускоряется ровно настолько, чтобы уложиться.

### Фоновый звук (`js/ambient.js`, `docs/sounds/`, около 16 МБ)

Пользователь отверг синтезированные звуки: «слишком искусственно». Используются только живые записи, которые он выбрал сам. Звучат три слоя:

1. **Мелодия** — тихая, задаёт настроение (`MUSIC = 0.42`). Выбирается по времени суток:
   - утром по чётности дня: `kalimba` или `xiao`;
   - с 12:00 — `healing`;
   - с 17:00 — `temple`.

   Играет через `<audio>` → Web Audio. Элемент создаётся внутри касания (требование iOS). Мелодии идут потоком из сети, офлайн их нет.
2. **Природа** — петли: `fountain`, `wind`, `birds`, `drops`. Набор и громкость задают сцены `SCENES`: home, talk, breath, warmup, qigong, hold, strength, rest.
3. **Отдельные звуки** — чаша, гонг, колокольчики, деревянный блок. Звучат на счёт и дыхание (`beat`), а также в начале и в конце занятия (`chime`).

Пока говорит мастер, весь фон приглушается до 0,35. Общий уровень — `BASE = 0.8` × громкость из настроек.

Источники и лицензии:
- BigSoundBank — CC0;
- Jamendo через archive.org — CC BY-NC-ND 3.0;
- Kevin MacLeod — CC BY 4.0.

Авторы перечислены в настройках, в разделе «Авторы музыки и звуков».

### Лист программы и схемы упражнений

- Вкладка «Программа» — `js/sheet.js`. Строится той же `buildSession`, что и занятия: утро/день/вечер, дозировка
  (`doseRaw` хранит её без привязки к языку: `h:сек`, `b:дыханий:вдох:выдох`, `r:8+8`), щадящие пометки по флагам.
  `trackChanges()` сравнивает снимок программы с прошлым (`state.sheet`) и пишет «Что изменилось» с причиной из
  `program.history`. Сегодняшний мягкий режим/пропуски показываются бледными карточками.
- Схемы — `js/figures.js`: манекен рисуется SVG по углам суставов (вид сбоку: 0 — вниз, 90 — вперёд, 180 — вверх;
  вид спереди — с зеркалом по сторонам). Кадр 0 — сплошная начальная поза, остальные — тени; стрелки считаются
  по траектории сустава между кадрами (`arrows`), особые значки — `marks`. Реквизит: стул, стена, коврик, шар.
  Цвета из темы (`--ink`, `--seal`). Проверочная страница: `docs/figtest.html` (все схемы сеткой).
  Кадры уже подходят для анимации (функция `mix` интерполирует позы) — это следующий этап.
- Объяснения «Как выполнять» — `js/guides.js`, по предложению на запись; озвучены XTTS (входят в `dump.mjs`).

### Язык интерфейса

Ключом служит сам русский текст: `t('Русский текст', {var})`. Английский словарь `js/lang/en.js` собирается командой `python tools/i18n/build_en.py` из двух источников:
- `tools/i18n/keys.json`;
- переводов `en_part1–3.txt`, построчно выровненных с ключами.

Новые строки нужно обернуть в `t()` и дописать в словарь. Язык меняется с перезагрузкой приложения. ИИ отвечает на языке интерфейса.

Ловушка: не называйте локальные переменные `t`. Это уже ломало чат и анкету.

## Сервер (VPS ученика)

> На VPS уже работают другие сервисы пользователя. **Сначала посмотрите, что там есть, и ничего чужого не трогайте.**
> Ключи (`APP_TOKEN`, `ANTHROPIC_API_KEY`) лежат только в `/opt/taichi/server/.env`. **Никогда не просите пользователя прислать ключ в чат.**

- Код находится в `/opt/taichi` — это клон ветки `Тай-Чи`.
- Служба systemd `taichi` слушает `127.0.0.1:9170`.
- Caddy проксирует `taichi.aidemiko.ru` на `127.0.0.1:9170`. Блок добавлен рядом с другими сайтами, например `planner.aidemiko.ru` на порту 9100.
- Проверка: `https://taichi.aidemiko.ru/api/health` должен ответить `{"ok":true,"ai":true}`.
- Обновление:

```bash
cd /opt/taichi && git pull && cd server && sudo npm ci --omit=dev && sudo systemctl restart taichi
```

Подробности установки — в `server/README.md`.

## Что дальше

1. **Ждём отзыва о балансе фона.** Пользователь слушает пробную запись и проверяет на телефоне. Править нужно в `js/ambient.js`:
   - общий уровень `BASE`;
   - мелодию `MUSIC`;
   - громкость слоёв в `SCENES`;
   - частоту колокольчиков.

   После правки — поднять `VERSION` в `sw.js`.
2. По желанию: переозвучить записи о времени стояния, отмеченные проверкой распознаванием, например «сорок пять секунд» и «две с половиной минуты». Они в поле `check` файла `docs/audio/manifest.json`.
3. Порядок работы, о котором договорились:
   - пользователь выбирает из вариантов на слух или на вид, потом делаем;
   - всё проверяем перед отправкой;
   - отвечаем по-русски, простыми словами.

## Как работать с репозиторием

- Коммиты идут в ветку `Тай-Чи`, отправка — `git push -u origin Тай-Чи`. Сайт обновляется через 1–2 минуты.
- Пользователь — русскоязычный, обращается «брат». Ценит живое звучание и спокойный восточный стиль.
