# Telegram: бот и запуск сервиса

Сервис это один процесс на вашем компьютере или сервере: Telegram-бот с
кнопками подтверждения плюс планировщик. Он использует те же скрипты и те же
файлы в папке `trader/`, что и работа из чата Claude Code.

## 1. Создать бота

1. В Telegram откройте диалог с **@BotFather** и отправьте `/newbot`.
2. Придумайте имя (любое) и username бота, он должен заканчиваться на `bot`,
   например `solex_trader_bot`.
3. BotFather пришлёт токен вида `123456789:AAH...`. Это пароль от бота,
   сохраните его в менеджер паролей и никому не показывайте.
4. Там же полезно: `/setprivacy` не нужен, бот работает в личном чате.

## 2. Положить токен в переменную окружения

Так же, как с токеном песочницы, имя переменной `TELEGRAM_BOT_TOKEN`.

Windows, PowerShell:

```powershell
[Environment]::SetEnvironmentVariable("TELEGRAM_BOT_TOKEN", "123456789:AAH...", "User")
```

macOS или Linux:

```bash
echo 'export TELEGRAM_BOT_TOKEN="123456789:AAH..."' >> ~/.zshrc
```

Откройте новое окно терминала после этого.

## 3. Конфиг сервиса

```bash
cp service/config.example.json service/config.json
```

Пока оставьте `allowed_user_ids` пустым и запустите сервис (шаг 4). Напишите
боту `/start`: он ответит вашим Telegram id и больше ничего не сделает.
Впишите этот id в `allowed_user_ids`, например `[123456789]`, и перезапустите.
С этого момента бот слушает только вас. Любой другой человек, нашедший бота,
не получит ни одного ответа.

Остальные поля:

- `project_dir`: где лежит папка `trader/`, по умолчанию корень репозитория.
- `timezone_offset_hours`: 3 для Москвы.
- `market_hours`: запасные часы для задач с пометкой `market_hours_only`,
  будни с 10:00 до 18:50. Основной источник другой: задача `schedule` раз в
  день берёт у биржи через API календарь с праздниками и временем сессии
  и пишет его в `trader/state/schedule.json`. Пока файла нет, действуют
  запасные часы.
- `max_daily_loss_pct`: при падении портфеля на столько процентов с начала
  дня сервис включает стоп-кран и пишет вам.
- `jobs`: что и когда делать. `every_min` это период в минутах, `at` это
  время раз в день. Ни одна задача не отправляет ордера.

## 4. Запуск

Проверка без запуска бота (конфиг, оба токена, счёт в песочнице):

```bash
python3 service/run.py --check
```

Запуск:

```bash
python3 service/run.py
```

Бот напишет «Сервис запущен». Остановить: Ctrl+C. На Windows вместо
`python3` обычно `python`.

Чтобы сервис работал, компьютер должен быть включён, а процесс запущен. На
ноутбуке это нормально для песочницы. Для постоянной работы позже перенесём
на маленький сервер, это отдельный шаг.

## 5. Как выглядит работа

Утро. Задача `snapshot` запоминает стоимость портфеля на начало дня.
В торговые часы `quotes` обновляет цены, `alerts` проверяет ваши ценовые
правила и присылает «🔔 SBER at or above 320», `guard` следит за дневным
убытком. Вечером `digest` присылает итог дня: портфель, решения, стоп-кран.

Сделка. Вы пишете `/propose` (или `/rebalance`), сервис считает ордера по
целям и бюджету из `trader/`. `/risk` прогоняет их через лимиты. `/orders`
показывает каждый ордер отдельным сообщением с двумя кнопками. Первое нажатие
«Подтвердить» показывает тикет ещё раз с вопросом «Отправить?». Второе
нажатие «Да, отправить» записывает ваше «да» в журнал (с вашим id и id
нажатия) и отправляет один ордер брокеру. Ответ брокера появляется в том же
сообщении. Кнопка привязана к точному содержимому ордера: если файл ордеров
изменился, старая кнопка откажет и попросит `/orders` заново.

Стоп-кран. `/stop причина` блокирует отправку любых ордеров, `/resume`
снимает. Сторож включает его сам при дневном убытке больше лимита.

## 6. Безопасность

- Бот отвечает только id из `allowed_user_ids`. Остальных игнорирует молча.
- Ордер отправляется только с кнопки, нажатой разрешённым пользователем,
  только через `tinvest.py order`, который сам ещё раз проверяет PASS
  риск-менеджера за сегодня и записанное «да» за сегодня.
- Планировщик не может отправить ордер: у него нет такой функции.
- Токены только в переменных окружения. В сообщениях бота их нет.
- Сетевые запросы только к api.telegram.org и хостам Т-Банка, через общий
  модуль с белым списком.
- Если телефон с Telegram потерян: в BotFather `/revoke` отзывает токен бота,
  на id.tbank.ru отзывается токен брокера. Это две минуты.
