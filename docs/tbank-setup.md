# Т-Банк: брокерский счёт и токены T-Invest API

Пошаговая инструкция для подключения пакета `trader-skill` к Московской бирже
через Т-Инвестиции. Шаги 1 и 2 делаются один раз, шаг 3 повторяется, когда
токен истекает.

Источник по токенам: официальная документация T-Invest API (раздел «Токен»),
прочитана 2026-11-04 из репозитория RussianInvestments/investAPI.

## 1. Брокерский счёт

Что понадобится: паспорт РФ, телефон с приложением Т-Банка, ИНН обычно
подтягивается сам.

1. Если вы ещё не клиент Т-Банка: закажите дебетовую карту на tbank.ru или в
   приложении. Представитель банка привозит карту и оформляет договор, после
   этого доступны все продукты, включая инвестиции.
2. В приложении Т-Банка откройте раздел «Инвестиции» и нажмите «Открыть
   брокерский счёт». Это обычный брокерский счёт, не ИИС. Для нашей задачи
   нужен именно обычный счёт: по ИИС есть ограничения на вывод, а
   Инвесткопилка через API торговать не может.
3. Проверьте данные, подпишите договор кодом из СМС. Счёт обычно открывается
   в течение нескольких минут, иногда до одного рабочего дня.
4. Тариф оставьте базовый «Инвестор», для старта он подходит. Сменить можно
   позже.
5. Для первых шагов пополнять счёт не нужно: работа начинается в песочнице,
   где деньги виртуальные.

Важно про квалификацию. Часть инструментов доступна только квалифицированным
инвесторам или после тестирования в приложении. Адаптер отказывается
выставлять ордер по такой бумаге, пока вы не разрешите это в конфиге.

## 2. Выпуск токенов

Токенов нужно два, а лучше три. Выпускаются они на сайте, не в приложении.

1. Откройте https://www.tbank.ru/invest/settings/ и войдите.
2. Отключите функцию «Подтверждение сделок кодом». Иначе заявки через API
   не пройдут. Сделки дороже 30 млн рублей через API недоступны в любом
   случае.
3. Найдите блок «Токены T-Invest API» и выпустите токены по одному:
   - **Токен песочницы.** Выберите «Песочница». Это первый токен, с ним
     работаем ближайшие недели.
   - **Токен только для чтения.** Выберите «Биржа», уровень «Только чтение».
     С ним аналитика видит реальный портфель и котировки, но не может ничего
     купить или продать. Понадобится на этапе, когда захотим смотреть на
     настоящий счёт.
   - **Токен с полным доступом.** Выберите «Биржа», уровень «Полный доступ».
     Можно ограничить одним конкретным счётом, и это стоит сделать. Выпускать
     его сейчас не нужно. Он нужен только для реальных сделок.
   Система может попросить войти ещё раз: это нормально.
4. Токен показывается один раз. Скопируйте его сразу в менеджер паролей.
   Повторно посмотреть нельзя, только выпустить новый. Количество токенов
   не ограничено.

Срок жизни токена: три месяца с момента последнего использования. Если API
отвечает ошибкой 40003 «authentication token is missing or invalid», токен
истёк или отозван: выпустите новый.

Отозвать токен: https://id.tbank.ru/account, раздел безопасности. Отзывайте
сразу, если токен попал в чат, в скриншот, в git или на чужой компьютер.

## 3. Куда положить токены

Токены живут только в переменных окружения или в файле вне репозитория.
Никогда: в чате, в `trader/config.json`, в git, в скриншотах.

Linux и macOS, в файле `~/.bashrc` или `~/.zshrc`:

```bash
export TINVEST_SANDBOX_TOKEN="t.ваш_токен_песочницы"
```

Windows, PowerShell, один раз (сохраняется для пользователя):

```powershell
[Environment]::SetEnvironmentVariable("TINVEST_SANDBOX_TOKEN", "t.ваш_токен_песочницы", "User")
```

После этого откройте новый терминал. Для боевого контура позже аналогично
`TINVEST_TOKEN`, и в момент реальной сделки ещё `TINVEST_LIVE=yes`.

Альтернатива: файл с токеном в одну строку вне проекта, например
`~/.config/tinvest/sandbox.token` с правами только для владельца, и флаг
`--token-file` у команд адаптера.

## 4. Первый запуск в песочнице

В папке проекта (там, где лежит `trader-skill/`):

```bash
cp trader-skill/trader-tinvest/config.example.json trader/config.json
```

```bash
python3 trader-skill/trader-tinvest/tinvest.py sandbox open --name robot
```

Команда напечатает номер счёта. Впишите его в `trader/config.json` в поле
`account_id`. Затем:

```bash
python3 trader-skill/trader-tinvest/tinvest.py sandbox payin 100000
```

```bash
python3 trader-skill/trader-tinvest/tinvest.py whoami
```

```bash
python3 trader-skill/trader-tinvest/tinvest.py quote SBER LKOH GAZP --write
```

Если `whoami` показывает счёт со статусом OPEN и уровнем FULL_ACCESS, а
`quote` печатает цены, подключение работает. Дальше обычная цепочка пакета:
budget, risk, broker, и `tinvest.py order --index N` после вашего «да».

## 5. Что проверить перед выходом на реальный счёт

Это не на сегодня, но чтобы было записано:

- Две-четыре недели работы в песочнице без ошибок в журнале
  `trader/state/broker.json`.
- Токен с полным доступом выпущен для одного счёта, не для всех.
- В `trader/config.json` лимиты выставлены осознанно: `max_order_usd`,
  `max_position_pct`, `max_orders_per_day`, `cash_buffer_pct`.
- Первая реальная сумма такая, которую не жалко потерять целиком.
- `TINVEST_LIVE=yes` задаётся только на время конкретной команды, не
  постоянно в профиле оболочки.
