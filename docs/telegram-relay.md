# Свой ретранслятор Telegram Bot API на Cloudflare

Нужен, когда api.telegram.org напрямую не доходит, а подходящего HTTP-прокси
нет. Ретранслятор это крошечная программа на бесплатном Cloudflare Workers,
которая принимает запросы сервиса и пересылает их в Telegram. Она ваша, код
ниже на 25 строк, посторонних звеньев нет. Cloudflare из России доступен,
именно через него работает приложение TG WS Proxy.

Важно: ретранслятор видит токен бота, поэтому он должен быть только вашим.
Чужими «публичными ретрансляторами» пользоваться нельзя.

## 1. Аккаунт Cloudflare

1. https://dash.cloudflare.com/sign-up, регистрация по почте. Бесплатный план.
2. Подтвердите почту и войдите.

## 2. Создать Worker

1. В меню слева «Workers & Pages», кнопка «Create», затем «Create Worker».
2. Имя, например `tg-relay`. Нажмите «Deploy».
3. Нажмите «Edit code». Удалите весь текст в редакторе и вставьте содержимое
   файла `docs/telegram-relay/worker.js` из репозитория. Нажмите «Deploy»
   в правом верхнем углу.
4. Вернитесь на страницу Worker. В «Settings», «Variables and Secrets»
   нажмите «Add»: тип Secret, имя `RELAY_KEY`, значение любая длинная
   случайная строка, например 30 букв и цифр. Сохраните. Эту строку
   запомните, она нужна на шаге 3.
5. Адрес Worker показан на его странице, вид
   `https://tg-relay.<ваш-аккаунт>.workers.dev`. Откройте его в браузере:
   ответ `forbidden` означает, что всё работает и ключ требуется.

Если адрес `workers.dev` у вас не открывается (бывает заблокирован), в
настройках Worker раздел «Domains & Routes» позволяет привязать свой домен.
Напишите, если так, разберём отдельно.

## 3. Переменные окружения на ноутбуке

Подставьте свой адрес и свою строку ключа:

```powershell
[Environment]::SetEnvironmentVariable("TELEGRAM_API_BASE", "https://tg-relay.ваш-аккаунт.workers.dev", "User")
```

```powershell
[Environment]::SetEnvironmentVariable("TELEGRAM_RELAY_KEY", "ваша_длинная_строка", "User")
```

Закройте PowerShell, откройте новое окно, перейдите в папку проекта и:

```powershell
python service\run.py --check
```

Ожидается `bot: @ваш_бот, project: ..., via relay https://tg-relay...`.

## Как это устроено

Сервис отправляет те же запросы, что и в api.telegram.org, только на адрес
Worker и с заголовком `X-Relay-Key`. Worker сверяет ключ, пересылает запрос
в Telegram и возвращает ответ как есть. Т-Банк по-прежнему напрямую.
Бесплатного лимита Cloudflare (100 000 запросов в день) хватает с запасом:
сервис делает около 4 000 запросов в день.
