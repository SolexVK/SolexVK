# Веб-панель: включение, домен и HTTPS

Панель это страница, которую отдаёт сам торговый сервис: стоимость портфеля,
результат по каждой бумаге, график, доли против целей, ордера, ждущие
решения, фоновые задачи и журнал. Кнопок подтверждения на ней нет, они
остаются в Telegram. Данные берутся из файлов `trader/`, сеть не нужна.

## 1. Включить панель на сервере

Сервис слушает только на `127.0.0.1`, снаружи напрямую его не видно.
Придумайте секрет (длинная случайная строка, не короче 16 символов):

```bash
python3 -c "import secrets; print(secrets.token_urlsafe(24))"
```

Впишите его в `service/config.json` в блок `web`:

```bash
sudo nano /opt/trader/app/service/config.json
```

```json
  "web": {"host": "127.0.0.1", "port": 8787, "secret": "ВАША_СТРОКА", "public_url": "https://trade.ваш-домен.ru"},
```

`public_url` это адрес, по которому панель будет открываться снаружи после
шага 2. Пока домена нет, оставьте пустым: ссылка будет локальной.

```bash
sudo systemctl restart trader && sudo journalctl -u trader -n 5 --no-pager
```

В логе появится строка `panel: ...`. В Telegram команда `/panel` присылает
ссылку. Ссылка содержит секрет: кто её знает, тот видит портфель. Никому
не пересылайте, при утечке поменяйте секрет и перезапустите сервис.

## 2. Домен и HTTPS через Caddy

Caddy сам получает и продлевает сертификат. Нужны: домен или поддомен,
направленный A-записью на IP сервера, и открытые порты 80 и 443.

1. В DNS домена создайте A-запись `trade` (или любое имя) на IP сервера.
   Проверка: `dig +short trade.ваш-домен.ru` возвращает IP.
2. Установить Caddy (Debian):

```bash
sudo apt-get install -y debian-keyring debian-archive-keyring apt-transport-https curl && curl -1sLf 'https://dl.cloudsmith.io/public/caddy/stable/gpg.key' | sudo gpg --dearmor -o /usr/share/keyrings/caddy-stable-archive-keyring.gpg && curl -1sLf 'https://dl.cloudsmith.io/public/caddy/stable/debian.deb.txt' | sudo tee /etc/apt/sources.list.d/caddy-stable.list && sudo apt-get update && sudo apt-get install -y caddy
```

3. Конфиг Caddy, подставив свой домен:

```bash
sudo tee /etc/caddy/Caddyfile >/dev/null <<'CADDY'
trade.ваш-домен.ru {
    reverse_proxy 127.0.0.1:8787
    header {
        X-Robots-Tag "noindex"
        Referrer-Policy "no-referrer"
    }
}
CADDY
sudo systemctl reload caddy
```

4. Проверка: `https://trade.ваш-домен.ru/` отвечает пустой страницей 404
   (так и должно быть, без секрета ничего нет), а ссылка из `/panel`
   открывает панель.

Если на сервере уже есть другой веб-сервер на портах 80 и 443, напишите,
подключим панель к нему.

## 3. Панель внутри Telegram

Когда HTTPS-адрес работает, у бота появится кнопка «Панель», открывающая
её внутри Telegram (Mini App). Для этого в `public_url` должен быть
HTTPS-адрес. Это следующий шаг после домена.

## Что на панели

- Стоимость портфеля, изменение за день от утреннего снимка.
- Вложено, результат в рублях и процентах по портфелю и по каждой бумаге:
  средняя цена покупки из лотов, текущая цена, доля.
- График стоимости: точки пишутся утром, каждые 10 минут в торговые часы и
  вечером. Появляется со второй точки.
- Цели против факта и отклонение. Отклонение от 5 пунктов подсвечено.
- Ордера, ждущие решения, с их статусом от риск-менеджера.
- Фоновые задачи с временем последнего запуска и результатом.
- Журнал решений: одобрено, отклонено, отправлено, не удалось.
