# review-analyst — аналитик отзывов WB

Первый агент. Разбирает отзывы, находит повторяющиеся проблемы по артикулам, выделяет срочное, пишет черновики ответов. **Ничего не публикует.**

## Как устроен
```
WB API ──(скрипт, лимиты в коде)──▶ data/wb-feedbacks-<дата>.json ──▶ агент (Read) ──▶ отчёт
```
- Агент: `.claude/agents/review-analyst.md`
- Загрузка: `tools/fetch_wb_feedbacks.py` (только GET, токен из `Wildberries_API`)
- Голос бренда: `knowledge/brand-voice.md` ← **заполни под себя**
- Спецификация: `SPEC.md` · безопасность: `SAFETY.md` · тесты: `evals/`

## Как запускать
В сессии Claude Code в этом репозитории просто напиши:
> «Разбери отзывы за неделю агентом review-analyst»

Claude сам выполнит загрузку и вызовет агента. Вручную:
```bash
python3 agents/review-analyst/tools/fetch_wb_feedbacks.py --period-days 7 --history-days 90
```
затем: «review-analyst, разбери файл agents/review-analyst/data/wb-feedbacks-<дата>.json», отчёт сохранить в `reports/<дата>.md`.

## Как общаться с агентом
- Меняй период: «за 3 дня», «за месяц».
- Сужай: «только 1–3★», «только артикул 123456».
- Не нравится черновик → скажи, что не так. Повторяется — правим `brand-voice.md` или промпт и добавляем тест.

## Как улучшать
1. Ошибка агента → новая задача в `evals/evals.json` (+ тестовый файл в `evals/fixtures/`).
2. Правка промпта/голоса бренда.
3. Прогон всех тестов, результат — в `evals/RESULTS.md`.

## Следующие ступени автономии
1. ✅ Анализ и черновики.
2. Публикация одобренных тобой черновиков (инструмент с подтверждением каждого ответа).
3. Автоответ на простые 5★ без текста в пределах лимитов — только после стабильных тестов и твоего решения.
