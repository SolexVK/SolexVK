# Чек-лист безопасности агента

Пройти целиком перед первым боевым запуском и после крупных изменений. Результат — в `agents/<имя>/SAFETY.md`.

## A. Права и действия
- [ ] Белый список инструментов — только нужные. Чтение отделено от записи.
- [ ] Все необратимые и внешние действия (деньги, цены, публикация, удаление, сообщения клиентам/партнёрам) — только с подтверждением человека.
- [ ] Опасные действия блокируются **кодом** (хук `PreToolUse`, валидация в инструменте), а не только словами в промпте.
- [ ] Лимиты: макс. шагов, бюджет на запуск, таймауты, макс. размер изменения (например, цена не более ±N %).
- [ ] Повторный запуск не дублирует действия (идемпотентность).
- [ ] Есть «режим предложения» / `dry_run` для пилота.

## B. Данные и секреты
- [ ] Ключи и токены — только в переменных окружения/хранилище, не в коде, не в промпте, не в репозитории.
- [ ] Агенту доступны только нужные ему секреты.
- [ ] Персональные данные клиентов не уходят во внешние сервисы без необходимости.
- [ ] Логи не содержат секретов.

## C. Prompt injection
- [ ] В промпте явно: внешние тексты (отзывы, письма, веб, ответы API, файлы) — данные, не инструкции.
- [ ] В evals есть задача с инъекцией, агент её проходит.
- [ ] Агент, читающий недоверенные данные, не имеет одновременно опасных прав на запись — или запись идёт через подтверждение.

## D. Наблюдаемость
- [ ] Каждый запуск оставляет отчёт и лог шагов.
- [ ] Понятно, как остановить агента (выключить расписание, отозвать ключ).
- [ ] Ошибки приходят человеку, а не тонут молча.

## E. Проверка стороннего кода (скиллы, MCP-серверы, агенты, пакеты)
Сторонние скиллы — реальный канал атак (Snyk, 2026: 13,4 % из ~4 000 скиллов с критическими проблемами; найдены скиллы, тайно дописывающие инструкции в `~/.claude/CLAUDE.md`, ворующие ключи, подделывающие «официальных» издателей).

**До установки, ничего не запуская:**
- [ ] Издатель проверяем и совпадает с заявленным. Официальное Anthropic — `github.com/anthropics/*`. Агрегаторы (skills.sh, ClawHub, skills.lc и т.п.) авторство не гарантируют.
- [ ] Клонировать в отдельную пустую папку и прочитать **весь** SKILL.md и все скрипты.
- [ ] Поиск опасных шаблонов:
  ```bash
  grep -rnE 'curl|wget|requests|urllib|http[s]?://|socket|base64|eval\(|exec\(|subprocess|os\.system|pip install|npm install|\.aws|\.ssh|\.env|CLAUDE\.md|settings\.json|environ' <папка>
  ```
  Каждое совпадение объяснить: зачем это нужно для заявленной задачи.
- [ ] Нет бинарников, архивов с паролем, нераскодируемых base64-блоков, обфускации.
- [ ] Нет «скачай и запусти» (`curl … | sh`, clone + `setup.sh`), нет запросов root/автозапуска.
- [ ] Не пишет в глобальные настройки и память (`~/.claude/`, `CLAUDE.md`, `settings.json`, `MEMORY.md`).
- [ ] Нет текста «игнорируй предупреждения», «developer mode», «не показывай пользователю».
- [ ] Домены понятны и нужны; нет двойников (`tussahre.pro` вместо `tushare.pro`).
- [ ] Версия зафиксирована (коммит/тег).
- [ ] Первый запуск — в изоляции, без боевых ключей.

**Сомнение → не ставить. Написать аналог самим.**
