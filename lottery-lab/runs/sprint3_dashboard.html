Каждая стратегия на каждом из 23 043 тиражей видит только прошлое, делает ставку и сравнивается с реальным результатом — честный walk-forward, как торговый бэктест.

Почему это честно, а не подгонка

Walk-forward: стратегия никогда не видит будущее — только историю до текущего тиража. Null-модель: сравнение со случайным выбором, чьё ожидание = 0.6944. FDR: при 7 стратегиях один сырой p<0.05 ожидается случайно — например «repeat-last» даёт p≈0.02, но z отрицательный (хуже!) и поправку не проходит. Вердикт строится на FDR, а не на сырых p.

Проверь свою гипотезу

Добавь функцию в lab/backtest.py → STRATEGIES: def s_my(counts, last, t, prev, rng): return [...5 чисел...] — и запусти python3 scripts/run_backtest.py. Она пройдёт тот же самый барьер: walk-forward, случайный null, FDR.
