# Спринт 2 — Движок выплат и EV (5x36plus)

## 1. Экономика билета (эмпирически, по фактическим выплатам)

| Показатель | Значение |
|---|---|
| Цена билета | 75 ₽ |
| **Реальный RTP** (выплачено ÷ ставки) | **51.8%** → house edge **48.2%** |
| Возврат по тирам (доля ставки) | 2из5 14.2% · 3из5 21.9% · 4из5 4.1% · СУПЕР 11.6% |

Вероятности тиров — точная комбинаторика, **подтверждённая фактом**: СУПЕР выигран **S1=18** раз (ожидание 19.3), **S2=58** (ожидание 58.0). Совпадение подтверждает структуру: СУПЕР №1 = 5 из 5 + «плюс» (1 к 1 507 968), СУПЕР №2 = 5 из 5 без «плюс» (1 к 502 656).

## 2. Rollover: бывает ли EV положительным? (H011)

- Средний возврат нижних тиров = 29.5 ₽/билет. Чтобы EV дошёл до цены 75 ₽, джекпот СУПЕР №1 должен достичь **≈66 млн ₽**.
- Максимальный джекпот за историю данных: **18.8 млн ₽** (в среднем 5.7 млн).
- **Вывод: положительного EV не бывает** — потолок джекпота почти вчетверо ниже порога. Игра всегда с отрицательным ожиданием.

## 3. Популярность чисел у игроков (H010)

⚠️ **Игроки выбирают числа НЕравномерно** (тир «2 из 5», p=0.0020; статистика T=2.52e-04 против null 2.19e-06).
Робастность на тире «3 из 5»: p=0.0020.

- Корреляция «популярность ↔ значение числа» (Спирмен): **-0.499** — меньшие числа популярнее.
- Разрыв «календарные 1–31 vs 32–36»: +4.29e-03 побед/ставку.
- Чаще выбирают: **17, 11, 7, 9, 21, 3** · реже: **34, 35, 30, 1, 36, 32**.

> Как это измерено: при равномерном выборе число победителей нижнего тира не зависит от того, *какие* числа выпали. Если же выпадают числа, которые игроки выбирают чаще, совпадений (победителей на ставку) становится больше. Отклонение сравнивается с null-моделью (2000+ симуляций равномерного выбора).

## 4. Где это даёт реальный эдж

Нижние тиры — **фиксированные**, поэтому популярность НЕ меняет твою выплату в них. Единственное место, где выбор непопулярных чисел повышает *ожидаемую* выплату — **делимый СУПЕР-джекпот**: при совпадении ты делишь его с меньшим числом людей. В абсолюте вероятность СУПЕРа ничтожна (1 к 1,507,968), поэтому практический прирост EV микроскопический — но он реален и посчитан честно.
